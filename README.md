# Multi-Level GAN-Based Enhanced CT Scans for Liver Cancer Diagnosis

This repository contains the source code and supporting scripts associated with the following publication:

**Khan RA, Luo Y, Wu FX. Multi-level GAN based enhanced CT scans for liver cancer diagnosis. _Biomedical Signal Processing and Control_. 2023;81:104450.**  
https://doi.org/10.1016/j.bspc.2022.104450

## Overview

The code provided in this repository was developed as part of the research presented in the publication above.

The study investigates a **multi-level generative adversarial network (GAN)-based approach for enhancing CT scans for liver cancer diagnosis**.

This repository is made available to support:

- research reproducibility;
- academic and educational use;
- comparison with related methods;
- further methodological development; and
- extension of the proposed approach.

Users should refer to the original publication for complete details regarding the methodology, datasets, experimental design, implementation, and evaluation.
